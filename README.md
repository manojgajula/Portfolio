# Manoj Gajula — Professional Portfolio

Responsive portfolio website built with **HTML, CSS and vanilla JavaScript**.

## Sections
Home · About · Skills · Projects · Experience · Achievements · Certifications · Contact

## Run locally
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` with Live Server, or open it directly in a browser.

## Customize before publishing
- Verify phone, email and LinkedIn details in `index.html`.
- Add GitHub repository and live demo links to the project cards when available.
- Add a resume download link if desired.
- Update styles in `style.css`; colors are defined in `:root`.
- Update interactions in `script.js`.

## Deploy
You can publish this folder using GitHub Pages, Netlify or Vercel.
